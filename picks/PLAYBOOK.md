## 2. 상품 고르기 (상품 2개: 카드뉴스 1, 쇼츠 1, 서로 다른 상품)
1. `picks/topics_log.md` 를 읽고 최근 30일 안에 다룬 상품은 피한다.
2. **인스타 분석 (크롬, 꿀템 인스타 로그인 상태)**: `picks/benchmark_accounts.md` 계정들의 최근 7일 게시물에서 반응(좋아요·댓글) 높은 상품군을 본다. 목록이 5개 미만이면 #살림템 #살림꿀템 #자취꿀템 #주방꿀템 검색으로 잘 되는 계정을 찾아 추가한다. 안전 규칙: 이동마다 3~5초 쉬기, 계정 5개까지, 좋아요·팔로우·댓글·DM 금지, 경고·로그인 요구 시 즉시 중단. 남의 문구·사진은 가져오지 않는다.
3. 계절·시기(예: 겨울 결로, 김장, 대청소)와 웹 검색 트렌드를 더해 후보 3~4개.
4. **교차 검증**: Claude 앱 내장 브라우저로 chatgpt.com, gemini.google.com 에 후보와 핵심 사실을 보여주고 "인스타 살림템으로 반응 좋을 순서, 과장·사실 오류"를 묻는다. 못 하면 "⚠️ 교차 검증 못 함(이유)".
5. 피할 상품: 의약품·건강기능식품·의료기기(효능 표현 규제), 성인용품, 담배·주류, 위험물, 리뷰가 적거나(100개 미만) 평점 4.0 미만인 상품.

## 3. 쿠팡 파트너스 링크 만들기 (크롬, 쿠팡 파트너스 로그인 상태)
1. https://partners.coupang.com 홈의 **상품검색**에 상품명을 검색한다.
2. 리뷰 많고 평점 높은 상품 1개를 골라 **링크 생성(URL 생성)** 버튼으로 파트너스 단축 링크(`https://link.coupang.com/a/...`)를 만든다. 페이지 글로 링크를 읽어 확인한다. 구매·결제·설정 변경은 절대 하지 않는다.
3. `picks/links.json` 의 items 에 `{"no": 다음 번호, "name": 상품 이름(짧게), "note": 한 줄 소개, "url": 파트너스 링크, "date": "YYYY-MM-DD"}` 를 추가하고 `python3 tools/build_links.py` 로 링크 페이지를 다시 만든다.
4. 로그인 화면이 뜨면 로그인하지 말고 멈춘 뒤 "⚠️ 쿠팡 파트너스 로그인 필요"를 보낸다.
5. 최종 승인 후 GitHub Secrets 에 `COUPANG_ACCESS_KEY`·`COUPANG_SECRET_KEY` 가 생기면 API 방식으로 바꾼다(사용자가 알려줌).

## 4. 카드뉴스 (content.json) — 형식은 `samples/picks/content.json` 참고
- 반드시 포함: `"ad_label": "광고 · 쿠팡 파트너스"`, `"theme"`, `"brand": "@jangbaguni0916"`, `"store_tag": ["장바구니","구출작전"]`, `"store_name": "장바구니 구출작전"`, `"avatar_text": "장"`, `"post_at"`.
- 6장: 1 hero(`tag` 비주얼: kicker "오늘의 꿀템 N번", 상품 이름, 한 줄 장점) → 2 문제(이런 불편 있죠?) → 3 해결(이 상품이 어떻게) → 4 사용법·팁 → 5 "프로필 링크 → N번" → 6 follow(head: "매일 살림 꿀템이 궁금하다면" / "@jangbaguni0916 팔로우하세요!").
- 가격은 숫자로 쓰지 않는다(수시로 바뀜). "링크에서 오늘 가격 확인"으로 쓴다. "최저가", "무조건", 효능·의학적 표현 금지. 써 본 것처럼 쓰지 않는다(직접 사용 후기 아님).
- **실물 사진 필수 (2026-11-02 사용자 요청, 모든 작업에 적용)**: 카드뉴스는 링크 번호·팔로우 장을 뺀 모든 장에 실제 상품 사진(판매자 상품 이미지 또는 사용자가 준 사진)을 `{"kind":"photo","src":"p_xxx.jpg","card":true,"size":620,"top":130}` 로 넣는다. 사진 없이 tag/big 비주얼만으로 만들지 않는다.
- `caption.txt`: 후킹 1줄 → ✔️ 장점 3줄 → "프로필 링크 → N번에서 확인" → 댓글 유도 질문 → 해시태그 10개 이내(#살림템 #살림꿀템 등). 대가성 문구와 꼬리말은 게시할 때 자동으로 맨 앞·뒤에 붙으니 넣지 않는다.

## 5. 쇼츠 (script.json) — **상황극 형식이 기본 (2026-11-04 사용자 승인, 16절 참고)**
- 반드시 포함: `"ad_label": "광고 · 쿠팡 파트너스"`, `"store_tag": ["장바구니","구출작전"]`, `"post_at"`, `"yt_title"`(끝에 #Shorts), `"yt_tags"`, `"cast"`, `"opening"`.
- 25~45초. 오프닝 3초 안에 공감형 후킹. 마지막 대사: 프로필 링크 N번 + 좋아요·팔로우.
- `"opening": {"headline": "후킹 문구"}` — **"광고 포함 영상입니다" 음성(내레이션)은 넣지 않는다 (2026-11-05 사용자 요청, 모든 쇼츠).** 오프닝·첫 장면 narration·대사 어디에도 광고 고지 음성을 넣지 않는다. 광고 표시는 화면의 "광고 · 쿠팡 파트너스"(모든 장면), 캡션 대가성 문구, 유튜브 유료 프로모션 표시로 한다.
- 형식 예시: `picks/shorts/samples/dialogue-humidifier/script.json`
- `caption` 규칙은 카드뉴스와 같다(해시태그 끝에 #Shorts). push 하면 GitHub 이 영상을 만든다(쇼츠 영상 제작 작업, 2~3분). 완료 후 pull, 프레임 확인.

## 10. 규정 체크 (게시 전 매번, 하나라도 걸리면 고친다)
**쿠팡 파트너스·공정위 추천보증 심사지침**
- 캡션 첫 줄과 마지막 줄에 대가성 문구 원문(자동). 해시태그를 쓰면 첫 해시태그는 #광고 #쿠팡파트너스(자동).
- 카드 모든 장 왼쪽 위·쇼츠 모든 장면 오른쪽 위 "광고 · 쿠팡 파트너스"(쇼츠 음성 고지 "광고 포함 영상입니다"는 2026-11-05 사용자 요청으로 넣지 않음).
- 써 보지 않은 상품을 써 본 것처럼("써보니", "제가 매일 써요") 쓰지 않는다. 구매 후기 문장을 그대로 옮기지 않는다.
- 쿠팡 로고·"쿠팡 공식" 표현 금지. 가격 숫자·"최저가"·"역대급 할인" 금지("가격은 링크에서 확인").
- 내 파트너스 링크를 직접 클릭하거나 클릭을 유도하는 보상 금지. 상품명은 링크가 아니라 파트너스 상품검색 화면에서 확인한다.
**표시광고법**
- "100% 차단", "완벽", "무조건", "최고", 효과 수치(난방비 30% 절감 등)는 근거 없으면 금지 → "~에 도움", "~일 수 있어요".
- 판매자 이미지 속 안전·인증·시험 문구("무독성", "인증 완료")는 옮기지 않는다(이미지째 쓰지 않음).
**유튜브**
- 업로드 시 '유료 프로모션 포함' 표시(post_shorts.py 자동). 제목·썸네일은 영상 내용과 일치. 남의 영상·음원 재사용 금지(직접 만든 배경음악만).
**인스타**
- 저작권: 상품 사진은 사용자가 준 것만, 출처 문제 시 즉시 교체. 남의 릴스 영상·음원 재사용 금지.
- 카드뉴스 마지막 follow 장에는 실제 인스타 프로필 화면(assets/picks_profile.png)이 자동으로 들어간다.

## 12. AI 영상 장면 (Google Flow, 2026-10-28 추가)
- 쇼츠 장면에 `"clip": "<폴더>/파일.mp4"` 를 넣으면 그 영상 위에 글자가 얹힌다. 화면 왼쪽 위에 "AI 생성 장면"이 자동 표시되고, 유튜브 업로드 시 합성 콘텐츠 표시가 자동으로 켜진다.
- AI 장면은 상황·문제·분위기 장면만. 상품을 쓰는 장면, 효과 전후 비교는 AI로 만들지 않는다(상품은 실제 상품 사진).
- Flow(flow.google.com)는 크롬(사용자 구글 계정)에서 만든다: 9:16, x1, Veo 3.1 Fast(20크레딧). 생성 전 크레딧 확인 창에서 "승인"만 누른다(항상 승인 금지). 프롬프트 끝에 "No faces, no text, no logos, no brand products." 다운로드는 720p 원본 → 다운로드 폴더 → device_stage_files 로 가져온다.
- 하루 AI 클립은 최대 2개(월 크레딧 한도). 크레딧이 모자라면 AI 장면 없이 만든다.

## 13. Flow AI 장면 (2026-11-04부터 선택 사항 — 기본은 16절 상황극 + 오프닝 라이브러리)
- 구성: 1 AI 상황 장면(후킹 질문 headline) → 2~4 실제 상품 사진 장면(사용자가 준 사진 또는 판매자 상품 이미지, 안전·인증 문구 이미지는 제외) → 마지막 '프로필 링크 N번' + 좋아요·구독·팔로우.
- 상품 장면(2~4)에는 반드시 실제 상품 사진을 넣는다(2026-11-02 사용자 요청, 모든 쇼츠). 사진을 못 구했으면 tag/big 으로 대신하지 말고 초안 맨 위에 ⚠️ 로 알리고 사진부터 구한다.

### Flow AI 첫 장면 만드는 순서 (매번, 2026-10-28 확정)
1. 크롬(claude-in-chrome)에서 https://flow.google.com 의 기존 프로젝트를 열거나 "새 프로젝트". 사용자 구글 계정으로 이미 로그인되어 있다(로그인 화면이면 건너뛰고 초안 맨 위에 ⚠️).
2. 에이전트 설정: 동영상 9:16, x1, 모델은 Veo 3.1 Fast(20크레딧). "생성하기 전에 확인: 항상" 유지.
3. 프롬프트(영어): 장면 묘사 + "realistic smartphone-style vertical video, 8 seconds, no dialogue. No faces, no text, no logos, no brand products." 크레딧 확인 창에서 **"승인"** 한 번만 누른다("항상 승인" 금지). 1~2분 뒤 완료.
4. 영상 편집 화면 → 다운로드 아이콘 → **720p 원본 크기**. 크롬 다운로드 폴더에 `제목_xxxx.mp4` 로 저장된다.
5. `device_request_folder_access` 로 `~/Downloads` 접근을 요청(이유: "Flow AI 영상을 쇼츠에 넣기 위해")하고, `device_list_dir` 로 방금 받은 mp4 를 찾아 `device_stage_files` 로 가져와 쇼츠 폴더에 `ai_scene.mp4` 로 복사한다. 직접 연 크롬 탭은 닫는다.
6. script.json 첫 장면에 `"clip": "<쇼츠 폴더>/ai_scene.mp4"`. 화면의 "AI 생성 장면" 표시와 유튜브 합성 콘텐츠 표시는 자동.
7. 어느 단계든 실패(로그인, 크레딧 부족, 폴더 접근 거부, 3분 넘게 생성 안 됨)하면 AI 장면 없이 기존 방식으로 만들고 초안 맨 위에 "⚠️ AI 장면 없음(이유)"을 적는다. 게시 시각을 놓치지 않는 것이 우선.
- AI 장면 내용: 상황·문제·분위기만(사람 손, 방 안, 창문, 휴대폰을 든 손 등). 실제 상품을 쓰는 장면, 효과 전후, 실존 브랜드·로고·실제 기기 모델은 만들지 않는다.
- 영상 제작은 리모션(글자 애니메이션·장면 전환)으로 자동 처리된다(build.json 의 engine 확인, ffmpeg 면 리모션 실패로 기존 방식 사용된 것).

## 16. 상황극 쇼츠 (2026-11-04 사용자 승인: "실물 사진 + 재미있는 대본 + 진짜 사람 같은 대화")
**구성**
- 오프닝 3초: 무료 영상 라이브러리(`assets/openings/`)에서 자동으로 붙는다. 드라이브에 오프닝 파일을 올린 날은 그 영상이 우선. 분류를 정하려면 `"opening": {"library": "clean|unbox|home|phone"}`.
- 대사 장면 3~5개: 각 장면 배경은 **실제 상품 사진**(15절)을 `tools/photo_clip.py` 로 만든 영상(`"clip"`, `"ai_label": false`). 장면마다 `"headline"`(짧은 정보 한 줄)과 `"lines"`(대사 2~4개).
- 등장인물은 2명(예: 엄마·아들, 자취생 룸메 둘, 신혼부부). `"cast"` 에 목소리를 정한다:
  `"cast": {"엄마": {"voice": "ko-KR-SunHiNeural"}, "아들": {"voice": "ko-KR-HyunsuMultilingualNeural", "side": "right"}}`
  여자 목소리는 SunHi, 남자는 Hyunsu(가장 자연스러움) 또는 InJoon. 오른쪽 인물은 노랑 말풍선.
- 대사 형식: `{"who": "아들", "text": "통째로? ...진짜?", "rate": "+15%", "pitch": "+18Hz", "volume": "-10%", "fx": "far", "gap": 0.3}` (rate·pitch·volume·fx·gap 은 선택).
- 말풍선 자막·"※ 연출된 상황극입니다" 표시·방 울림 효과·배경 영상 이어짐은 영상 제작기가 자동 처리한다.

**대사를 사람처럼 쓰는 규칙 (국어책 말투 금지)**
- 한 대사는 짧게(20자 안팎). 정보 문장을 그대로 읽지 말고 인물이 반응하는 말로 바꾼다: "물통이 분리됩니다" ✗ → "어, 뭐야. 진짜 쑥 빠지네?" ○
- 구어체: 줄임·말끝 흐리기(...), 되묻기("통째로? ...진짜?"), 감탄("오", "어휴", "헐"), 귀찮은 대답("아 알았어, 알았어..."), 혼잣말.
- 갈등 → 발견 → 반응 → 결말 순서: 잔소리/불편 → 상품 발견 → 놀람·확인 → "나 이거 시켰어" / "진작 좀 하지!" 같은 웃긴 마무리.
- 말투에 맞춰 조절: 귀찮은 대답은 `"rate": "+20%", "volume": "-10%"`, 놀람은 `"pitch": "+15Hz"`, 다른 방에서 부르는 첫마디는 `"fx": "far"`. 대사 사이 쉬는 시간 `gap` 0.1~0.4.
- 같은 인물이 연달아 말해도 된다(혼잣말). 내레이션 없이 대사만으로 정보가 전달되게 쓴다.

**지켜야 할 것**
- 상품 정보는 쿠팡 상품 페이지에 실제로 적힌 것만(기능·구성·후기 수 등). 효과를 단정하지 않는다("완벽", "끝" ✗ → "헹구면 되네", "도움 돼" ○).
- 실제로 써본 후기처럼 말하지 않는다: "내돈내산", "한 달 써봤는데" 금지. 상황극 안의 반응("쑥 빠지네?")은 상품 사진·상세에 나온 기능 범위 안에서만.
- 가격은 대사에 넣지 않는다(변동). 마지막 대사에 "링크는 프로필에, N번" + 좋아요·팔로우.
- 초안 메시지에 대사 전문을 함께 보낸다.
