# 장바구니 구출작전 플레이북 (인스타 @jangbaguni0916 · 유튜브 "장바구니 구출작전")

쿠팡 파트너스 수익용 생활 꿀템·살림템 계정. 예약 작업이 실행될 때마다 이 문서를 그대로 따른다.

## 0. 시간 (한국 시간, 매일)
| 작업 시작 | 카드뉴스 게시 | 쇼츠 게시 | 폴더 |
|---|---|---|---|
| 12시대 | 13:00 | 13:30 | `picks/drafts/YYYY-MM-DD-1300/`, `picks/shorts/drafts/YYYY-MM-DD-1330/` |
| 16시대 | 18:00 | 18:30 | `picks/drafts/YYYY-MM-DD-1800/`, `picks/shorts/drafts/YYYY-MM-DD-1830/` |

## 1. 승인 방식
- **2026-11-11 까지**: 초안을 보내고 사용자가 "게시해줘" 하기 전에는 절대 approved 로 옮기지 않는다.
- **2026-11-12 부터**: 아래 7단계 '자동 게시 전 검사'를 모두 통과하면 바로 approved 로 옮기고, 게시 링크를 사용자에게 알린다. 검사 하나라도 실패하면 자동 게시하지 않고 초안으로 보내 확인을 받는다.

## 2. 상품 고르기 (상품 2개: 카드뉴스 1, 쇼츠 1, 서로 다른 상품)
1. `picks/topics_log.md` 를 읽고 최근 30일 안에 다룬 상품은 피한다.
2. **인스타 분석 (크롬, 꿀템 인스타 로그인 상태)**: `picks/benchmark_accounts.md` 계정들의 최근 7일 게시물에서 반응(좋아요·댓글) 높은 상품군을 본다. 목록이 5개 미만이면 #살림템 #살림꿀템 #자취꿀템 #주방꿀템 검색으로 잘 되는 계정을 찾아 추가한다. 안전 규칙: 이동마다 3~5초 쉬기, 계정 5개까지, 좋아요·팔로우·댓글·DM 금지, 경고·로그인 요구 시 즉시 중단. 남의 문구·사진은 가져오지 않는다.
3. 계절·시기(예: 겨울 결로, 김장, 대청소)와 웹 검색 트렌드를 더해 후보 3~4개.
4. **교차 검증**: Claude 앱 내장 브라우저로 chatgpt.com, gemini.google.com 에 후보와 핵심 사실을 보여주고 "인스타 살림템으로 반응 좋을 순서, 과장·사실 오류"를 묻는다. 못 하면 "⚠️ 교차 검증 못 함(이유)".
5. 피할 상품: 의약품·건강기능식품·의료기기(효능 표현 규제), 성인용품, 담배·주류, 위험물, 리뷰가 적거나(100개 미만) 평점 4.0 미만인 상품.

## 3. 쿠팡 파트너스 링크 만들기 (크롬, 쿠팡 파트너스 로그인 상태)
1. https://partners.coupang.com 홈의 **상품검색**에 상품명을 검색한다.
2. 리뷰 많고 평점 높은 상품 1개를 골라 **링크 생성(URL 생성)** 버튼으로 파트너스 단축 링크(`https://link.coupang.com/a/...`)를 만든다. 페이지 글로 링크를 읽어 확인한다. 구매·결제·설정 변경은 절대 하지 않는다.
3. `picks/links.json` 의 items 에 `{"no": 다음 번호, "name": 상품 이름(짧게), "note": 한 줄 소개, "url": 파트너스 링크, "date": "YYYY-MM-DD"}` 를 추가하고 `python3 tools/build_links.py` 로 링크 페이지를 다시 만든다.
4. 로그인 화면이 뜨면 로그인하지 말고 멈춘 뒤 "⚠️ 쿠팡 파트너스 로그인 필요"를 보낸다.
5. 최종 승인 후 GitHub Secrets 에 `COUPANG_ACCESS_KEY`·`COUPANG_SECRET_KEY` 가 생기면 API 방식으로 바꾼다(사용자가 알려줌).

## 4. 카드뉴스 (content.json) — 형식은 `samples/picks/content.json` 참고
- 반드시 포함: `"ad_label": "광고 · 쿠팡 파트너스"`, `"theme"`, `"brand": "@jangbaguni0916"`, `"store_tag": ["장바구니","구출작전"]`, `"store_name": "장바구니 구출작전"`, `"avatar_text": "장"`, `"post_at"`.
- 6장: 1 hero(`tag` 비주얼: kicker "오늘의 꿀템 N번", 상품 이름, 한 줄 장점) → 2 문제(이런 불편 있죠?) → 3 해결(이 상품이 어떻게) → 4 사용법·팁 → 5 "프로필 링크 → N번" → 6 follow(head: "매일 살림 꿀템이 궁금하다면" / "@jangbaguni0916 팔로우하세요!").
- 가격은 숫자로 쓰지 않는다(수시로 바뀜). "링크에서 오늘 가격 확인"으로 쓴다. "최저가", "무조건", 효능·의학적 표현 금지. 써 본 것처럼 쓰지 않는다(직접 사용 후기 아님).
- 상품 사진은 쓰지 않는다(사용자가 직접 찍어 준 사진만 `photo` 로 사용 가능).
- `caption.txt`: 후킹 1줄 → ✔️ 장점 3줄 → "프로필 링크 → N번에서 확인" → 댓글 유도 질문 → 해시태그 10개 이내(#살림템 #살림꿀템 등). 대가성 문구와 꼬리말은 게시할 때 자동으로 맨 앞·뒤에 붙으니 넣지 않는다.

## 5. 쇼츠 (script.json) — 형식은 `shorts/drafts/2026-10-28-sample/script.json` 참고
- 반드시 포함: `"ad_label": "광고 · 쿠팡 파트너스"`, `"store_tag": ["장바구니","구출작전"]`, `"post_at"`, `"yt_title"`(끝에 #Shorts), `"yt_tags"`.
- 5~7장면, 25~40초. 첫 장면 3초 안에 "이거 하나로 해결!" 같은 후킹. 마지막 장면: "프로필 링크 N번에서 확인하세요".
- 내레이션 첫 문장에 "광고 포함 영상입니다" 같은 짧은 고지를 넣는다.
- `caption` 규칙은 카드뉴스와 같다(해시태그 끝에 #Shorts). push 하면 GitHub 이 영상을 만든다(쇼츠 영상 제작 작업, 2~3분). 완료 후 pull, 프레임 확인.

## 6. 기록
- `picks/topics_log.md` 에 `- YYYY-MM-DD HHMM 카드|쇼츠: 상품명 (N번)` 추가.

## 7. 자동 게시 전 검사 (모두 통과해야 함)
- 카드 모든 장 왼쪽 위·쇼츠 모든 장면에 "광고 · 쿠팡 파트너스" 표시가 보인다.
- 캡션에 가격 숫자, "최저가", 효능 표현이 없다.
- links.json 에 이번 번호의 링크가 있고 `https://link.coupang.com/` 으로 시작한다.
- 링크 페이지(docs/picks/index.html)를 다시 만들어 커밋했다.
- 글자 넘침·겹침이 없다(모든 장·장면 직접 확인).

## 8. 게시
- 승인(또는 자동 게시 조건 충족) 후 `git mv picks/drafts/<폴더> picks/approved/<폴더>`, `git mv picks/shorts/drafts/<폴더> picks/shorts/approved/<폴더>` → 커밋 → push.
- 게시 시각이 아직 안 됐으면 이 세션에서 `send_later` 로 게시 시각 1분 뒤 알림을 걸고, 알림이 오면
  `gh api -X POST repos/yet933781-creator/cardnews/actions/workflows/picks-post.yml/dispatches -f ref=main` 로 직접 게시한다.
- 게시 후 posted.json 의 링크(인스타, 릴스, 유튜브)를 사용자에게 알린다.

## 9. 참여 유도 (모든 카드뉴스·쇼츠, 2026-10-28 추가)
- 카드뉴스 마지막 follow 장에는 "좋아요 · 댓글 · 저장 / 유튜브 구독도 부탁드려요" 띠가 자동으로 들어간다(render.py). 지우지 않는다.
- 쇼츠 마지막 장면 narration 끝에 "도움 됐다면 좋아요, 구독·팔로우 부탁드려요!"를 넣고, 그 장면 caption 은 "좋아요 · 구독 · 팔로우!" 류로 쓴다.
- 캡션에는 상품과 관련된 진짜 질문 1줄(댓글 유도)과 "저장해 두세요" 1줄을 넣는다. 참여 유도 꼬리말(좋아요·댓글·저장·팔로우·구독)은 picks/footer.txt 에서 자동으로 붙는다.
- 금지: 좋아요·댓글·구독의 대가로 경품·할인·추첨을 약속하는 문구("댓글 달면 추첨", "구독하면 쿠폰"), "좋아요 안 누르면" 같은 압박, 친구 태그 강요.

## 10. 규정 체크 (게시 전 매번, 하나라도 걸리면 고친다)
**쿠팡 파트너스·공정위 추천보증 심사지침**
- 캡션 첫 줄과 마지막 줄에 대가성 문구 원문(자동). 해시태그를 쓰면 첫 해시태그는 #광고 #쿠팡파트너스(자동).
- 카드 모든 장 왼쪽 위·쇼츠 모든 장면 오른쪽 위 "광고 · 쿠팡 파트너스", 쇼츠 첫 문장 "광고 포함 영상입니다".
- 써 보지 않은 상품을 써 본 것처럼("써보니", "제가 매일 써요") 쓰지 않는다. 구매 후기 문장을 그대로 옮기지 않는다.
- 쿠팡 로고·"쿠팡 공식" 표현 금지. 가격 숫자·"최저가"·"역대급 할인" 금지("가격은 링크에서 확인").
- 내 파트너스 링크를 직접 클릭하거나 클릭을 유도하는 보상 금지. 상품명은 링크가 아니라 파트너스 상품검색 화면에서 확인한다.
**표시광고법**
- "100% 차단", "완벽", "무조건", "최고", 효과 수치(난방비 30% 절감 등)는 근거 없으면 금지 → "~에 도움", "~일 수 있어요".
- 판매자 이미지 속 안전·인증·시험 문구("무독성", "인증 완료")는 옮기지 않는다(이미지째 쓰지 않음).
**유튜브**
- 업로드 시 '유료 프로모션 포함' 표시(post_shorts.py 자동). 제목·썸네일은 영상 내용과 일치. 남의 영상·음원 재사용 금지(직접 만든 배경음악만).
**인스타**
- 저작권: 상품 사진은 사용자가 준 것만, 출처 문제 시 즉시 교체. 남의 릴스 영상·음원 재사용 금지.
