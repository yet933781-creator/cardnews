# 업무 흐름 (③단계 V2.0)
1. 상품 리서치 AI가 후보 및 출처 조사.
2. 확인 가능한 지표로 우선순위 평가; 미확인 수치 추측 금지.
3. 기획 AI가 카드뉴스/릴스 원고·캡션·제휴 고지 작성.
4. 제작 AI가 사용 권한이 확인된 자료로 이미지·영상 제작, 파일 검수.
5. 운영 AI가 상품 정보·광고 표시·제휴 링크·이미지 권리·게시 계정 검수.
6. 사용자에게 최종 미리보기와 링크를 보여주고 명시적 승인 요청. 수정 시 해당 담당으로 반려하고 다시 검수·승인.
7. 연동 및 권한이 검증된 경우에만 승인된 최종본 게시, 실제 게시 결과 확인.
8. 실제 인사이트·클릭·전환·수익을 분석하고 다음 상품 선정 개선.
독립적인 조사와 권리 확인은 서브에이전트 지원 시 병렬 수행 가능. 지원되지 않으면 역할별 순차 진행. 같은 파일 동시 수정 금지.
피드백은 우선 이번 작업에 적용하고 '앞으로도/기본으로/매뉴얼에 저장' 등 명시적 요청 시 공통 규칙을 갱신한다.
