# 인기 상품 자동 발굴 기준 (③단계 V2.0)
허용된 데이터 접근 범위에서 쿠팡 상품 정보·인기 지표, 네이버 데이터랩 검색 관심 추이, 인스타그램 계정 인사이트, 쿠팡 파트너스 실적을 조사한다. 연동은 아직 검증되지 않았다.
초기 평가 가중치(추천안): 검색 관심·상승 추세 30, 확인 가능한 인기·판매 관련 지표 25, 내 계정 반응 20, 콘텐츠 적합성 15, 제휴 적합성 10.
데이터가 없으면 임의 점수를 만들지 말고 '확인 불가'로 기록한다. 상대적 검색 관심도는 실제 검색 횟수가 아니며 공개 인기 순위는 확정 판매량이 아니다.
상품마다 식별 정보, 출처 링크, 확인 시각, 가격 확인 시각, 장단점, 콘텐츠 아이디어, 제휴 링크 확인 여부, 이미지 사용 권한을 남긴다. 실제 판매량 1위나 예상 수익을 근거 없이 주장하지 않는다.
