# AI 담당별 업무 기준 V1.0 (②단계 승인)
1. 상품 리서치: 상품 후보 5개 조사, 출처/확인시점/특징/장단점/추천대상/불확실성 기록. 허위 판매량, 순위, 할인율, 체험담 금지. 결과물: 검증 가능한 후보 목록.
2. 콘텐츠 기획: 확인된 상품정보를 토대로 친근한 존댓말, 첫 문장에 핵심 문제나 이점, 카드뉴스 5~6장 또는 릴스 15~30초(초기 추천 기준). 결과물: 장별 원고 또는 장면별 대본, 캡션, 명확한 제휴 고지. 과장 및 근거 없는 주장 금지.
3. 제작: 권한이 확인된 AI/사용자 제공 이미지·영상 혼합, 카드뉴스 1080×1350, 릴스 9:16, 모바일 가독성·자막 일치·영상 재생 점검. 결과물: JPG/MP4, 표지, 경로. 기존 렌더러 우선 활용.
4. 운영·수익 관리: 게시 전 사실·링크·이미지 권리·광고 표시 검수, 정확한 최종본의 사용자 명시적 승인 확보, 승인 후에만 게시, 게시 결과 기록, 확인 가능한 실제 수치만 보고. 실패를 성공으로 보고하지 않음.
각 담당은 다음 담당에게 출처, 입력자료, 결과물, 미확인 항목, 검수 상태를 전달한다.
