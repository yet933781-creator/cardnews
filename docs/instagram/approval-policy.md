# 게시 승인 규칙 (필수)
RESEARCH → DRAFT → PRODUCED → PREFLIGHT → AWAITING_APPROVAL → APPROVED → QUEUED → POSTED 또는 FAILED.
사용자는 게시할 정확한 이미지·영상, 캡션, 제휴 고지, 링크, 계정을 확인한 후 명시적으로 승인해야 한다. 운영안 승인이나 침묵은 개별 게시 승인으로 간주하지 않는다.
승인 후 콘텐츠 또는 링크가 바뀌면 승인을 다시 받는다. 거절되면 게시 중단, 수정 후 재검수·재승인.
기존 README의 approved/ 폴더는 자동 게시 트리거일 수 있으므로 실제 동작 검증 전에는 새 콘텐츠를 넣지 않는다.
API 키·비밀번호·토큰은 문서, 코드, 채팅, 로그에 저장하지 않는다. 게시 실패를 성공으로 기록하지 않으며 중복 재시도에 주의한다.
